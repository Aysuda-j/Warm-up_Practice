# Warmup Practice
A collection of small foundational programming exercises in C and Java, built while getting comfortable with core language mechanics, I/O, and — for two of them — structuring code progressively from a quick first pass into a cleaner, function-based version.

## Projects

| Project | Language | Description |
|---|---|---|
| [`palindrome-checker`](./palindrome-checker) | C | Checks whether an input string reads the same backward as forward |
| [`numbers-guessing-game`](./numbers-guessing-game) | Java | A Mastermind-style number guessing game, built across three stages — from a fixed hardcoded version to a generalized, function-based one |
| [`temperature-converter`](./temperature-converter) | C | Converts between Celsius, Fahrenheit, and Kelvin, also built across three progressive versions |

Each project has its own README with more detail — the two multi-stage ones (`numbers-guessing-game` and `temperature-converter`) walk through what changed at each step and why.

## Why this repo exists
These started out as separate one-off practice repos. Grouping them here keeps the profile focused on projects that actually show range, instead of scattering small exercises across a long repo list.
